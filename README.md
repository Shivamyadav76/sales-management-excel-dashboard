# Sales Management Excel Dashboard

This is a simple sales data analysis project created using Microsoft Excel.

#About the Project

The project uses sales data to understand sales performance, profit, products and different regions.

# Tools Used

* Microsoft Excel
* Pivot Tables
* Charts
* Basic Excel formulas

# Dashboard Includes

* Total Sales
* Total Profit
* Total Orders
* Total Quantity
* Sales by Region
* Sales by Category
* Monthly Sales Trend
* Top 5 Products

# Project File

The Excel workbook contains the sales data, analysis and dashboard.

*File:*`Sales_Management_Excel_Project.xlsx`

# Objective

The main objective of this project is to practice Excel-based data analysis and create a simple dashboard from sales data.

## Key Learning

Through this project, I practiced data cleaning, basic analysis, Pivot Tables and creating charts in Excel.
